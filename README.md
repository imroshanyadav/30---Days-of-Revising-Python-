# 30 Days of Revising Python 🐍

A 30-day daily practice log to revise Python fundamentals — from core syntax to the libraries that matter for AI/ML and DSA work.

## 🎯 Goal

Rebuild a strong, hands-on foundation in Python by writing code every single day for 30 days — no passive tutorial-watching, no copy-pasting. Struggle first, then verify.

## 📅 Structure

| Days | Focus |
|------|-------|
| 1–5  | Core syntax, data types, control flow, functions |
| 6–10 | OOP — classes, inheritance, magic methods |
| 11–15 | File handling, exceptions, comprehensions, iterators/generators |
| 16–20 | Standard library deep dive (collections, itertools, functools) |
| 21–25 | NumPy & Pandas basics for data handling |
| 26–30 | Mini-projects tying concepts together |

*(Feel free to tweak this plan as you go — update it here as the source of truth.)*

## 📁 Repo Layout

```
30-days-of-revising-python/
├── day01/
│   └── practice.py
├── day02/
│   └── practice.py
...
└── README.md
```

Each `dayXX/` folder contains:
- `practice.py` — code written that day
- `notes.md` — key takeaways, gotchas, things to revisit

## 📌 Rules

1. Commit every day — even a small commit counts, but *something* real must be pushed.
2. No copy-pasting AI-generated code without typing and understanding it first.
3. If a day is missed, note why in that day's `notes.md` and keep going — no restarting from Day 1.
